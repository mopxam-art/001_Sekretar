## ✅ 1. Что было сделано и исправлено

### 1.1. Интеграция системных HTTP/SOCKS прокси
* **Проблема:** Cloudflare Workers (выступающие в роли Reverse Proxy для обхода блокировок Groq) заблокированы на территории РФ, что делает невозможным их использование без системного VPN. 
* **Решение:** В приложение «Перо Блиц» была добавлена прямая поддержка классических HTTP/HTTPS прокси. Установлен и внедрен модуль `https-proxy-agent`, который перехватывает нативные Node.js `https` запросы к Groq API и маршрутизирует их через пользовательский прокси.

### 1.2. Настройки прокси в интерфейсе
* В раздел **"Система"** вкладок настроек было добавлено новое поле ввода **"HTTP/HTTPS Прокси"**. 
* Обновлено хранилище `secureStore.js`, чтобы параметр прокси (`httpProxy`) надежно сохранялся между перезапусками приложения.
* Теперь пользователю достаточно купить индивидуальный IPv4 прокси и вставить его в приложение, чтобы сервис стабильно работал в условиях блокировок.

## 📝 2. ИНСТРУКЦИЯ ПО НАСТРОЙКЕ ПРОКСИ (ВАЖНО)

Пользователи, покупающие индивидуальные прокси (например, на proxy6.net или аналогичных сервисах), обычно получают 4 параметра:
1. **IP-адрес** (например, `192.168.1.15`)
2. **Порт** (например, `8000`)
3. **Логин** (например, `user99`)
4. **Пароль** (например, `secretPass`)

**КАК ПРАВИЛЬНО ВПИСАТЬ ПРОКСИ В ПРИЛОЖЕНИЕ:**

В поле настроек приложения прокси должен вставляться **одной сплошной ссылкой (URL)** строго по следующему шаблону:

```text
http://ЛОГИН:ПАРОЛЬ@IP-АДРЕС:ПОРТ
```

**Пример заполнения:**
Если ваши данные:
- IP: `192.168.1.15`
- Порт: `8000`
- Логин: `user99`
- Пароль: `secretPass`

То в настройки Перо нужно вставить ровно эту строку:
`http://user99:secretPass@192.168.1.15:8000`

*(Обратите внимание: без пробелов, логин и пароль разделяются двоеточием, затем идет символ `@`, затем IP-адрес, двоеточие и порт).*
