## ✅ 1. Исправления и технические улучшения

### 1.1. Исправление аудиопотока и улучшение качества распознавания
* **Проблема:** При быстром темпе речи модель Whisper на Groq иногда путала слова или обрывала фразы. Причиной являлся вызов `recorder.start(500)` в `useAudioRecorder.ts`, который нарезал аудиопоток на фрагменты по 500 мс, создавая микро-артефакты на стыках контейнера WebM Opus.
* **Решение:** Возвращён непрерывный целостный стриминг аудио (`recorder.start()`). Модель Whisper теперь получает монолитный чистый аудиофайл без микро-швов, что обеспечивает максимальную точность распознавания даже при высокой скорости диктовки.

### 1.2. Устранение бага двойной вставки текста
* **Проблема:** При обрывах или завершении диктовки транскрибированный текст вставлялся в активное окно дважды.
* **Решение:**
  - В `preload.js` устранена утечка слушателей IPC-событий с помощью карты обёрток `listenerWrappers`.
  - В `useAudioRecorder.ts` внедрён мьютекс (`isProcessingRef`), гарантирующий строго однократную обработку каждого записанного аудиофрагмента.

### 1.3. Устранение зависания таймера и сбоев записи
* **Решение:** Синхронизировано и централизовано состояние записи (`isRecordingActive`) между `sharedState.js`, `appEventHandlers.js` и оверлеем диктовки.

## 🌐 2. Сеть, Прокси и Безопасность ключей

### 2.1. Переключатель «Работать по прокси»
В интерфейс (вкладка **«Настройки» ⚙️**) добавлен удобный блок управления сетью:
* **Тумблер включения/выключения прокси:**
  - **Включено:** запросы идут через прокси (по умолчанию Tailscale `http://100.86.75.16:8888` или введённый вручную прокси). Позволяет работать из РФ без сторонних VPN.
  - **Выключено:** прямое соединение с `api.groq.com`. Используется, если на компьютере включен общесистемный VPN (VLESS, Outline, WireGuard) или пользователь находится вне РФ.
* **Кнопка «⚡ Проверить подключение»:** выполняет мгновенный тестовый запрос к Groq API и выводит результат с зелёной/красной индикацией прямо в интерфейсе.

### 2.2. Архитектура безопасности Groq API-ключа
* Из всех исходных файлов репозитория полностью удалены старые захардкоженные тестовые ключи.
* Ключ пользователя вводится вручную в настройках и сохраняется **исключительно на локальном компьютере** в зашифрованном файле конфигурации (`secureStore` с шифрованием AES-256 на базе аппаратного идентификатора машины).
* Ключ никогда не попадает в Git и на GitHub, что исключает блокировку со стороны GitHub Secret Scanning.

## 🚀 3. Система автообновлений (In-App Auto-Updater)

### 3.1. Модуль AutoUpdater
* На базе `electron-updater` создан `AutoUpdaterManager` (`electron/modules/autoUpdater.js`), поддерживающий автоматическую работу с GitHub Releases репозитория `mopxam-art/001_Sekretar`.
* Реализована автогенерация файла конфигурации `dev-app-update.yml` для стабильной работы и тестирования обновлений в режиме разработки (`start.bat`).

### 3.2. Интерфейс в приложении
В окне настроек добавлен раздел **«🚀 Обновление программы»**:
* Отображение текущей версии приложения (`Pero Blitz PRO v1.0.2`).
* Кнопка **«🔄 Проверить обновления»**.
* Прогресс-бар скачивания обновления в процентах.
* Кнопка **«🚀 Перезапустить и обновить»** после успешной загрузки новой версии.
