# Инструкция для ИИ (Проект: Перо Блиц)

## 1. Контекст проекта
Мы разрабатываем приложение **Перо Блиц** — десктопный клиент для голосового ввода с использованием искусственного интеллекта.
Основная кодовая база, над которой мы сейчас работаем, находится в папке: `C:\II\АНТИГРАВИТИ\001_Sekretar\Pero Blitz` (внимание: **не** в `app` и **не** в `app_lite`).
Стек: Electron + React + Vite + TypeScript.

## 2. Что уже сделано
- **UI и Настройки**: Мы перенесли обновленный дизайн (темная тема без сломанного переключателя светлой темы).
- **Горячие клавиши (Hotkeys)**: Мы починили логику записи горячих клавиш. Был добавлен фикс, предотвращающий падение вкладки "Настройки" из-за значения `null` в памяти настроек. Сейчас вкладка "Настройки" временно переведена в Debug Mode для тестирования рендеринга.
- **Статистика**: Исправлена верстка нулей на вкладке "Статистика" (задана фиксированная ширина колонок `width: 80px` в `StatisticsTab.css`), чтобы числа выстраивались ровно друг под другом.
- **Бэкенд n8n и Groq API**:
  - Было выявлено, что бесплатный API ключ Groq отклонял аудиофайлы (403 Forbidden), потому что Groq заблокировал IP-адрес сервера пользователя. Решение: использование HTTP Proxy в ноде n8n.
  - Было выявлено, что сервер Nginx (перед n8n) отклоняет длинные записи с ошибкой `413 Request Entity Too Large` (так как по умолчанию лимит загрузки 1 МБ). Требуется обновить `client_max_body_size 50M;` в конфигурации Nginx.

## 3. Что находится в процессе прямо сейчас
- Вкладка "Настройки" отображалась как пустой темный экран без текста. Мы перевели `Settings.tsx` в минимальный отладочный вид (Debug Mode), чтобы проверить, отображается ли хоть что-то. Если текст появится, нужно будет аккуратно вернуть оригинальный `Settings.tsx`, добавив еще больше проверок на `null/undefined` в данных настроек.
- Ожидаем от пользователя логин/пароль к SSH-серверу `n8n.fond-hub.ru`, чтобы зайти и изменить лимит Nginx. (Доступ без пароля не сработал).

## 4. Следующие шаги (Задачи впереди)
1. Успешно восстановить полный функционал вкладки "Настройки" (переключатель Toggle/Hold должен работать корректно, а сама вкладка не должна падать из-за поврежденного `settings.json`).
